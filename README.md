# FUTURE_UIUX_01 — NivaasCare Website Redesign

Responsive three-page website concept for **Future Interns UI/UX Design — Task 1: Local Service Business Website Redesign**.

## Pages
- `index.html` — homepage, service overview, process and enquiry CTA.
- `services.html` — deep cleaning, kitchen care and bathroom care.
- `contact.html` — lead enquiry form and contact information.
- `styles.css` — responsive styling.
- `script.js` — mobile navigation, service preselection and demo form feedback.
- `docs/design-rationale.md` — UX decisions and proposed conversion measures.

## Run locally
Open `index.html` in a browser. No build step or package installation is required.
